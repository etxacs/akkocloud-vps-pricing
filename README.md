## 拿到优惠码，在哪里填、能不能叠加？

Akkocloud 目前没有公开可用的码。如果你在别处看到一个声称能用的，按下面几步核验，别直接付款。

**填码的位置。** 结账页如果有 Promo Code 或“优惠码”输入框，把码粘进去点应用，金额会立刻刷新。购物车页面有时候没有这个框，往后走到结账那一步再看。填完先确认总价变了，再点支付。

**循环优惠和首期优惠是两回事。** 循环（Recurring）优惠每次续费都打折，长期用才划算；首期优惠只对第一次账单有效，第二年按原价续。看到“首年 X 折”这种表述，先算第二年要付多少。

**能不能和年付折扣叠加，要看码的规则。** 有的码能在年付价上再打一层，有的只对月付生效，还有的明确写着“特价套餐不参与”。判断方法很土但有效：把周期切到年付，填码，看价格变化；再切回月付，填同一个码，对比两次的结果。哪一个便宜就用哪一个。

**已经是年付特价的套餐，通常不能再叠年付折扣。** 这类套餐本身标的就是年付价，码只能再压一层，拿不到“年付 8 折再叠 9 折”那种双重效果。想叠得深，得从月付入口下单再切年付。

**码失效了先查两件事。** 一是套餐和周期在不在适用范围内，二是这个码是不是限量或已经到期。优惠码的半衰期以天计，很多活动截止到某个具体时间点，看到别人分享的码，先确认发布日期。
